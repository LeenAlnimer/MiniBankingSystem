# Mini Banking Transaction System

A backend banking system built with ASP.NET Core and designed using Clean Architecture principles.

## Overview

This project is a learning-focused banking transaction system that simulates core banking operations such as account management, deposits, withdrawals, transfers, and transaction history.

The project is designed to explore and apply backend development concepts and technologies used in real-world enterprise systems.

## Architecture

The system follows Clean Architecture with separated layers for:

- API
- Application
- Domain
- Infrastructure

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Redis
- RabbitMQ
- Hangfire
- Docker

## Features

- Customer management
- Account management
- Deposits and withdrawals
- Money transfers
- Transaction history
- JWT Authentication and Authorization
- Redis caching
- RabbitMQ messaging
- Background jobs with Hangfire
- External service integration
- Database performance optimization
- Docker containerization
- Unit and integration testing
